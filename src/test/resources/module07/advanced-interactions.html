Module 07 Learning Fixture - Advanced Selenium Gaps

Module 07 uses The Internet first for windows, nested frames, upload, hover, key presses, web table reading, and broken images. This local fixture exists only for mechanics that need exact, inspectable, deterministic HTML: a known download file, reliable drag/drop events, open Shadow DOM interaction, calendar/date-picker strategies, row action buttons, fixture-controlled sorting, and a hidden element for exception teaching.
